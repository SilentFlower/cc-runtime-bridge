# 原生内核准入研究

## 范围与结论

用户回复“按你建议来”已批准内核裁剪或调整构建基底，26.64 MiB 及原生行为目标保持不变。这里记录准入探针，不能代替最终工作进程、完整回归和速度验收。

固定 293 内核的接口探针经 ICU 资源裁剪、BCJ2/LZMA2 归档和 C 内存加载器打包后为 **26404920 字节（25.18 MiB）**。加载器不创建磁盘展开副本，校验载荷 SHA256 后写入封存 memfd，以 fexecve 在同一 PID 执行。单次接口导入探针约 2.233 秒，不是可服务初始化或模型请求性能。

## 基底筛选

- 固定原版为 Bun 1.4.3，revision=eecfd55debb281c3fe3518098b1a49f76429637c，源 SHA256=8968405e26db478af44eabc4635ab5ca557057b702a54460a59c13e1b253e978。
- 原版 global fetch 及 FetchSession 在独立 TLS 回环中均把合成 billing 的 cch=00000 改写为独立核算的正确值。
- 官方 stock Bun 1.4.4 与 vm2api 的 Bun 1.3.14 基底保留 00000，未通过该合同，未接纳为替代基底，也没有用 JS 补写。
- 保留原版原生代码，仅把全部 ICU 单项压缩资源还原后重新打包，得到 33104320 字节，仍超标，淘汰。

## ICU 裁剪边界

桥接进程一直使用 LANG=C.UTF-8，已支持的 MessageBody 和 ContextInput 不提供显示 locale 控制。候选保留 root、en 及全部 en_*、共享池和索引、所有非 locale 数据、完整 brkitr 目录；从 3990 个目录项保留 801 个，移除 3189 个 locale 定制资源，清零 5839120 字节。原生指令、字符/规范化数据和各语言分词规则/字典保留。

候选用于桥接工作进程，不能作为具有全部 Intl locale 定制的通用 CLI 分发。显式非英语日期、货币和排序定制不保证等同完整 ICU；需对当前固定默认 locale 和中文、阿拉伯文、泰文、组合字符及 emoji 的分词/正文做回归。不能宣称所有 Intl 调用与原版等同。

固定布局：ICU 头偏移 1524704、头长 144、TOC 基址 1524848、原目录项数 3990；共享 Zstd 字典偏移 13635856、长 131072、SHA256=ab8658c8ab8d5eb92f17b7c6625d2b39e19bf27e1752dafe5852522118ff1d01。只压紧 TOC，保留项数据和名称地址不动。正式构建必须解析、核验布局和原生节，不依赖临时研究 JSON。

## 打包与身份

- 7-Zip 26.05，官方发布 https://github.com/ip7z/7zip/releases/tag/26.05 。工具归档 SHA256=22cf82fcc6eb7474f1d5bb4f02c0f8ebd573a718089d6833dc30f8350a3b232e；C SDK 源归档 SHA256=0b6080b8c3e7a579161d2d495224c0e51c467576cb4c7048b0ab485ef44cc22e。
- BCJ2/LZMA2 参数：mx=9，主流 d=128m:fb=273，两个分支流 d=16m，mmt=1，mtm=off。
- SDK 静态编入加载器，运行不需要 7zz、liblzma、原版或提取目录；系统 libc 沿用双方既有系统依赖边界。
- 接口探针外层 SHA256=6575d486c3024333641b7653d66d35a0be625b3ed7a39c018405fc79472e0faf；实际执行体为 107199672 字节，SHA256=de877cbebdfa2ae292e9db12f84d8f2a4e6153c310e971522c4248134c32432c，Bun 1.4.3。
- /proc/self/exe 实测指向 /memfd:ccrb-native-runtime (deleted)，实际内容与上述载荷 SHA 一致。内存展开不是内存优化，额外驻留与峰值仍需单列。

## 原生请求验证进展

复用现有 preload.ts 的单轮逻辑，只把五组动态接口绑定替换为固定静态导入，编译得到 107211960 字节的候选。无外网命名空间、独立 HOME、合成 API key、TLS CONNECT 回环中，原版和未裁剪候选均得到 ready/cc_prepared/response_headers/response_chunk/completed，各发一次上游请求，响应字节一致，CCH 均为独立核算的 b88a9。

裁剪及内存加载后的真实单轮、默认 Intl/Unicode、最终常驻、多轮及配对性能结果后续追加。临时输入位于 /tmp/ccrb-kernel-admission；专有源、二进制和大资源不进入 Git。

## 完整单轮候选准入结果

内嵌真实单轮入口并完成 ICU 裁剪的载荷为 107211960 字节，SHA256=48a57ab58144e64b2db6014fd752d0cf4f197f2218b98a28079f683d0d85bc45；归档为 26349358 字节；可直接运行的完整加载文件为 **26404920 字节**，SHA256=eba06df55323c2393690b936d1484311bec762e4af9357832664ef9cec4b5d51。

在独立 HOME/cwd、无外网命名空间中，原版与打包候选均各发送一次 TLS 模型请求，五类协议事件顺序、响应字节及 CCH=b88a9 一致。固定默认 locale=en-US 的数字、日期、列表、大小写、Unicode NFKC，以及 en/zh/ja/th/ar 的词与字素分段结果全部一致。该候选通过进入正式构建与常驻集成的前置关卡；A1–A8 的最终验收仍针对后续实际交付产物。

## 首轮常驻性能结果及后续优化

正式交错五新进程、每进程六轮共 60 次实际请求，旧常驻候选（外层 3cf783d9…，载荷 48af79c7…）启动至首轮完成中位 3098.293 ms、就绪后首轮 170.196 ms、暖复用 9.567 ms；同轮 vm2api 为 3585.857/118.303/19.768 ms。总启动和暖复用通过，但就绪后首轮为标杆的 1.439 倍，A5 未通过，不能把该候选作为最终达标结果。原始证据见 performance-before-bootstrap/。

后续在隔离初始化根中调用同一官方构造器，发送前中止，只预先完成本地 SDK/依赖初始化；不调用实际发送入口，不产生模型请求、IPC 作业事件或持久业务日志。初始化成本全部计入总启动时间，仍须三项同时通过，不改变验收门槛。
