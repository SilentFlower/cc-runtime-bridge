# 技术设计

## 状态与边界

首次实施 Brief 已由用户确认。首版采用固定 293 的双阶段原生构造与发送，受支持 API、日志及页面通过离线验收后交付；真实 OAuth 和跨账号并发仍在本次范围之外。

项目提供原生桥接、日志采集与本地只读查看页面，后续可由 cc2api 接入。首版先完成单账号工作进程离线链路；并发能力后续独立验证。

## 结构与技术

- src/control：接收请求、工作进程生命周期、日志与只读查询。
- src/runtime/293：固定版本预加载、实体适配和原生发送观察。
- src/shared：内部消息、上下文、错误和采集阶段。
- web：日志列表、详情与原始数据查看。
- tests：策略、适配、流式及回环验证。

使用 TypeScript 和 ESM，控制进程采用 Bun，日志用 SQLite；页面先用原生 HTML、CSS 与 TypeScript。

## 请求链路

1. 接收结构化调用，记录脱敏入站数据。
2. 处理连接级字段、鉴权和上下文，生成头部决策。
3. 逐字段转换成官方内部实体，复用初始化、system 包装及 K_t/kon。
4. K_t 固定构造 stream=true，内部 fetchOverride 在发送前取得实际参数并中止生成阶段；此阶段不访问模型上游。
5. 使用官方 yN 客户端，按调用方 stream 标志执行一次实际请求；内部 fetchOverride 记录 cc_prepared 后调用默认 Ree。取得 Response 后暂不归还 SDK，向调用方返回响应逻辑字节，结束后释放等待，禁用重试。
6. 以一轮模型调用为边界返回 tool_use，工具由调用方执行。

K_t、yN、Ree 等仅对固定二进制有效。启动核对版本、SHA256 和接口，不匹配明确拒绝，不回退为版本字符串伪装。

## 内部合同

工作进程使用包含 schema_version、request_id 的 JSONL。每个作业新建官方进程并校验 hash，控制进程串行排队，stdout 只承载协议，stderr 单独排空；专用 HOME 和配置路径按显式环境传入，不能继承宿主账号配置。

请求区分 request_start、request_cancel；响应区分 response_headers、response_chunk、completed、error，并关联 attempt。片段采用可逆字节表示，不能解析重组 SSE 后冒充原始流。

头部使用有序多值列表。origin、代理、凭据来源及日志路径属于控制配置，不能由任意扩展头指定。

调用上下文包含类别、来源、session、prompt、agent 与父 agent。普通 API 无来源时使用标明默认来源的普通主上下文；显式子代理或压缩语义不得覆盖为 main。不支持的上下文明示错误。

## 头部与正文

完整规则见 docs/header-policy.md。未知合法扩展默认保留，鉴权和实际传输字段由原生运行时拥有；上下文同时影响头部、metadata 与 billing。

API 字段逐项建立映射和失败规则，无法表达的显式参数本地报错。请求头采用黑名单不代表可以任意透传所有 JSON 字段。

## 最终采集

研究已确认 cc_prepared 的 cch=00000 在原生发送后才变为最终值。当前没有找到可保留原生 FetchSession 行为的最终观察入口，因此 wire_final 明确保持 unavailable。隔离 TLS 接收端已验证原生最终 CCH。

全局 fetch 替换会影响 FetchSession 选择，仅用于实验。优先验证固定版本的原生观察入口；本地接收端用于独立核对。

没有真实最终采样时，页面显示 cc_prepared 与“最终值未采集”。不能重算后补写，不能宣传为完整最终抓包能力。真实最终值验证是后续生产接入门槛。

## 日志与页面

按 request ID、attempt 和阶段关联，合同见 docs/request-logs.md。SQLite 保存摘要及索引，正文独立有界保存，写入前脱敏。

详情使用请求发生时的快照，进程或账号失效后仍可查。查询不初始化 CC、不刷新凭据。

页面提供概览、头部处理、性能、原始数据，支持时间、模型、状态、类别、session 与 request ID 筛选。默认只监听回环地址，公开访问和账号管理不属首版。

## 流与故障

主响应优先，有界队列异步保存日志。写入故障记录可见缺口，不阻塞当前响应、不重放请求。

响应通道使用按消费需求交付的 ReadableStream，只容纳一个待消费片段；取消时主动拒绝该等待并结束字节流。它避免 TransformStream 写入等待期间中止无法可靠收口，以及 HTTP 已取消读端后重复中止写端的 Bun 管道问题。

取消传播到官方 AbortSignal，收口当前作业。HTTP 错误、SSE 错误、缺失终态和正常完成分别记录。

原生 fetch 可能解压响应，转发头须匹配实际逻辑字节；记录内容表示，不能把解压内容标成线上压缩字节。

## 验证与回退

验证使用空 HOME、合成凭据、无外网命名空间与本地 TLS 接收端，不自动触发真实账号或付费推理。

官方二进制和提取的专有源码不提交。本项目不切换现有 cc2api 正式链路，后续接入需单独对照与回退方案。
