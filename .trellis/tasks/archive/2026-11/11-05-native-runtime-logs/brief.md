# Brief — 官方 293 原生桥接与请求日志首版

## Goal

- 建立独立原生运行时桥接项目，保留请求语义，并让输入、处理及响应可记录、可查看。

## Scope

- 固定 2.1.293 的单账号串行桥接与结构化入参适配。
- 请求头黑名单、运行时字段归属及主会话／子代理等上下文关联。
- 请求日志保存、本地列表筛选、详情原文、头部处理原因及采集状态展示。

## Non-Goals

- 现有 cc2api 修复或生产切换、V4、完整账号池和计费平台。
- 首版的跨账号／同进程并行和公开管理服务。

## Technical Overview

- 入参经策略与上下文适配进入官方原生构造及发送，原始响应逻辑内容返回调用方；日志按阶段异步保存至本地存储，由只读页面查询。

## Context & Decisions

- 合法端到端扩展头默认保留；鉴权、版本身份、长度及编码由运行时负责。子代理类别、父子标识、session、metadata 和 billing 一起对齐。
- 293 已离线验证预加载、组装及响应截取，CCH 在更晚的原生发送阶段补齐；日志必须区分中间组装与真实最终采样。

## Risks

- 完整 API 适配和生产最终采样仍需验证；未取得最终值时明确显示未采集，不能用重算值补写。

## Acceptance

- 未知合法头保留，敏感与连接字段按规则处理；主会话、子代理和压缩请求分类及关联正确。
- 日志可筛选、看脱敏原文与处理原因，准确显示最终值、中间值、截断、未采集和失败。
- 合成回环验证响应内容、工具返回、取消和背压；日志故障不阻塞响应、不引发请求重放。

## Next Step
