# Brief — 可选缓存断点策略与遥测控制

## Goal

- 保持默认原生 CC 保真，让操作者按需选择缓存策略和遥测状态。

## Scope

- 缓存策略、遥测开关两个子任务，以及四种配置组合的集成回归。

## Non-Goals

- 页面管理、热切换、客户端遥测转发、付费缓存实验及防封效果评估。

## Technical Overview

- 启动配置经引擎白名单传入 worker，由能力握手核验；缓存处理在原生最终发送前完成，遥测采用官方后台链路。

## Context & Decisions

- CCRB_CACHE_POLICY=preserve/sub2api，默认 preserve；CCRB_TELEMETRY=off/on，默认 off，修改后重建服务。
- 固定官方 293，旧产物缺少显式开启能力时失败；保留中间值与最终出站的区分。

## Acceptance

- 原版与精简产物通过四组合、单次模型发送、日志兼容及离线回环验证；真实上游访问为零。
- 完成类型、构建、单元/集成及原生回归；精简产物不超过 27933052 B，记录启动与暖请求时间。

## Next Step

- 审阅两个子任务的完整组合验收证据，完成 Spec 与精确 Git 计划后的任务树交付。
