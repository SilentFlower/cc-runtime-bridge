## 命令约束

构建和验证：bun run build、bun run typecheck、bun run test、bun run test:integration、bun run test:native、bun run test:ui。实际终端记录为：控制与存储及单元测试 39 项、真实原生测试 14 项、浏览器测试 3 项通过，构建与类型检查通过；未另建验证报告附件。

协议验证使用合成数据、独立数据目录和无外网环境；失败后不能自动改用真实账号探测。

## 交接边界

首次实施范围与验收不变。实现采用“原生构造后中止、原生 SDK 单次实际发送”，原因是 K_t 固定流式且会消费响应；记录在 design.md。用户已确认 Git 发布计划，业务代码已推送至 GitHub 公开仓库 SilentFlower/cc-runtime-bridge；本任务记录按确认范围独立提交。
