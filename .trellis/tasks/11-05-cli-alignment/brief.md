# Brief — 对齐固定 293 交互终端 CLI

## Goal

- 让桥接的提示词、工具上下文和最终出站对齐原版交互终端 CLI，保留单轮调用、常驻隔离及部署体积预算，以可验证的安全与稳定为优先。

## Scope

- 接入原生 CLI 的默认 system、调用方工具声明、消息提醒及默认模型参数。
- 统一入口、消息来源、六类请求和父子关联，修正现有 SDK 路径残留。
- 同步原版与精简入口，重建并验收新产物，提供日志页面可查看的最终出站样本和配套说明。

## Non-Goals

- 不执行本地模型工具，不复刻终端 UI，不增加标题、建议等后台推理；不接入真实账号、生产或升级官方版本。
- 本轮不增加生产自动最终出站采集能力；本机 TLS 最终采样与该能力分别标明。
- 不继续追赶 vm2api 相对速度，不采用未完整回归的首发消费裁剪或录制请求模板，不承诺账号免封。

## Technical Overview

- 复用官方 CLI 的提示词、工具和上下文装配入口，在 K_t 的同一 SDK 发送上下文中由 Ree 唯一发送，桥接独占原始响应并取消原生解析；从独立本机 TLS 接收端核验最终正文和 CCH。

## Context & Decisions

- 参考固定官方 2.1.293 的真实交互主请求，使用 CLI 身份及 human 消息来源；已取得原版基线，-p 的 SDK 行为仅作差异对照。
- 用户已确认 tools 省略与 [] 均无工具；非空列表完整采用调用方定义，不加入 CC 内置工具。原生提示词与实际工具集保持一致，CLI 对照显式禁用工具。
- system 省略时采用 CLI 默认正文；显式值按 --system-prompt 替换正文，保留原生身份与归因。
- 保留已验证的六个纯正文缓存；动态上下文、钩子和原生归因仍逐轮处理，不扩大跨作业复用范围。
- 2026-11-05 用户已接受当前延迟，取消 vm2api 相对速度验收。CHK-001 保留 P1 和旧失败数据，按已接受风险处理；部署体积预算及安全、兼容约束继续有效。
- 保留单账号串行常驻、每轮新原生根、最多 16 个执行中或排队作业，以及故障退役、不重放的合同。

## Risks

- 当前暖复用慢于旧标杆，用户已接受；原生兼容及 CCH 只能证明已覆盖条件下的请求行为，不能保证账号不受平台限制。

## Acceptance

- 原版桥接和新的精简产物分别与匹配实际工具选择的真实 CLI 对照提示词、工具、消息环境、默认参数及归因；省略和 [] 均无工具，自定义列表不混入内置声明，system 替换保持有效，最终 CCH 独立核验。
- 六类关联、显式参数与工具/thinking 历史、流/非流、错误、取消及同 PID 多轮隔离通过；桥接每轮仅一次实际模型发送，真实上游请求为 0。
- 完整必需运行时部署文件总量 ≤27933052 B；保留启动至首轮、就绪后首轮、暖复用的实测和历史对照，初始化计入启动，不再要求 vm2api 相对速度达标。
- 页面展示本轮真实最终样本及来源，历史 SDK 记录和未实现的采集能力状态保持真实。

## Next Step

- 显式工具规则、重建、正式 full Check-All 与 Spec 评估已完成；业务代码已按确认计划提交并推送，无后续开发事项。
