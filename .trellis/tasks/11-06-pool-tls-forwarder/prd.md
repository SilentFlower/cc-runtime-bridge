# 本地 TLS 采集转发到池内 Messages

## Goal

通过本地 TLS 采集转发器观察 CC 真实最终出站，并使用池内 deepseek-flash 返回真实 Messages 响应。

## Background

- 用户确认开始，明确 Base URL 只改在本地 TLS 采集转发器；池子兼容 Messages，无需 OpenAI 协议转换。
- 现有 artifacts/native-cc-ingress-20261106/run-scenes.mjs:37–81 已使用独立 Node TLS 接收端保留 rawHeaders、最终正文和 CCH，但响应为本地合成；生产最终采集能力仍为 false。
- 当前业务基线 e3b4f66da523e52ded25db80cabcff63882b8aae；固定 293 来源和已接纳精简产物沿用现有合同。既有 pycache 不属于本任务。

## Requirements

- R1：CC 的原生目标、模型装配和发送行为保持；转发器先采集并独立核验完成 CCH 的真实请求，再把第二段目标改为池 Base URL、模型改为 deepseek-flash、凭据改为池 Key。
- R2：沿用 Messages 请求、JSON/SSE 响应协议；业务正文除第二段 model 外不主动裁剪，合法端到端扩展头保留，鉴权及传输字段的替换有明确记录。
- R3：CC 使用独立合成身份、HOME/config 和隔离网络，只能连接本地采集器；池凭据不作为配置或请求凭据传给 CC 工作进程。遥测关闭，不直接连接 Anthropic，不自动重试、重定向或回退其他模型。
- R4：分别记录测试入站、中间值、CC 最终出站、池转发请求及真实池响应；标明采集位置、表示、完整性、原始字节哈希和转换原因。正文和头部先脱敏再持久化，采集有界，失败和截断可见。
- R5：提供可重复的本地测试入口和只读报告页，展示两段请求差异、CCH 核验、响应及故障；保留现有预览和历史样本，不把测试能力改称生产自动采集已完成。
- R6：离线夹具覆盖原版/精简及流式、非流式、取消、失败和凭据泄露反例；显式池测试使用现有受保护配置，只读取 Base URL 和 Key，本轮固定 deepseek-flash，不沿用其中的 Gemini 主模型。
- R7：首轮真实池验收最多 3 次模型请求，串行覆盖非流式、流式及主动取消，每次 max_tokens 不超过 128；错误立即保留并停止后续真实调用。普通单元、集成和构建不触发真实池推理。

## Acceptance Criteria

- [x] AC1 / R1：原版与精简的真实 TLS 接收值有有效原生 CCH、原始有序重复头和可追溯身份，原始 CC 模型与第二段 deepseek-flash 分别可见。
- [x] AC2 / R2：本机池夹具只收到一个 Messages 请求，除明确 model/鉴权/传输处理外字段保留；完整 JSON/SSE 响应及错误状态正确返回，取消能终止转发。
- [x] AC3 / R3：CC 网络隔离及凭据白名单有实证，池 Key 未进入 CC 环境、入站、最终出站或持久样本；意外目标或路径拒绝，Anthropic 直连为零。
- [x] AC4 / R4、R5：只读报告可查看两段请求及真实响应，缺失、截断、取消和失败分别可辨认；秘密回显及跨片段边界不泄漏，历史预览不变。
- [x] AC5 / R6：类型、构建、定向单元/集成、原版与精简的本地回环、报告页面验证通过；运行时源码/身份未变时复用现有功能基线，不重建或另行授信。
- [x] AC6 / R7：最多 3 次真实池调用的次数、模型、预算、响应、CCH 和取消结果有可检查回执；无额外 Anthropic 或遥测调用，失败不以合成成功替代。

## Non-Goals

- 不改 CC 的 Base URL、默认工具、提示词或原生模块，不修改压缩配方或重建运行时。
- 不做 OpenAI 协议转换、真实 Anthropic/OAuth 验收、遥测开启、付费缓存命中实验或池内路由机制审计。
- 不新增生产代理、账号池管理、页面管理开关或生产 wire_final 自动采集承诺。
